# 63기 아카이브

63기 변리사 연수 기간용 플래너입니다. 월간·주간 일정을 보고, 소모임이 끝난 뒤 기록(참석자, 내용, 사진, 다음 모임 날짜)을 남길 수 있어요.
일정마다 작성자·수정자 이름이 함께 저장돼요.
왼쪽 인덱스에는 소모임 목록이 있어요. 일정을 추가할 때 새 소모임 이름을 적으면 자동으로 추가되고, 소모임마다 다른 색이 붙어요.

## 여는 방법
`index.html` 파일을 더블클릭하면 브라우저(크롬, 엣지 등)에서 열려요. 인터넷이나 설치는 필요 없어요.

## 파일 구조
```
patent63-archive/
├─ index.html      화면의 뼈대 (버튼, 입력창 위치)
├─ css/style.css   화면 꾸미기 (색, 크기, 휴대폰 화면 대응)
├─ js/utils.js     날짜·시간 계산 도구 (한국 시간, 24시간 표기)
├─ js/storage.js   데이터 저장 담당 ← 나중에 동기화할 때 이 파일만 바꾸면 돼요
├─ js/app.js       화면 그리기, 클릭 처리
├─ manifest.json   PWA(앱 설치)용 설정
└─ icons/icon.svg  앱 아이콘
```

## 꼭 알아둘 점
- 데이터는 **지금 쓰는 브라우저 안에만** 저장돼요. 다른 기기나 다른 사람에게는 보이지 않아요.
  (일정 글자는 localStorage, 사진은 IndexedDB라는 브라우저 저장 공간에 들어가요.)
- 브라우저의 "인터넷 사용 기록 삭제(쿠키·사이트 데이터)"를 하면 일정이 지워질 수 있어요. **가끔 "내보내기"로 백업**하세요.
- 다른 사람과 공유하려면: "내보내기"로 만든 파일을 보내고, 받은 사람이 "가져오기"하면 합쳐져요.

## 다음 단계 (예정)
1. 무료 호스팅(GitHub Pages 등)에 올려서 주소로 접속하기
2. PWA: 서비스 워커를 추가해 휴대폰 홈 화면에 앱처럼 설치하기
3. 동기화: `js/storage.js`를 Firebase·Supabase 같은 무료 서버 저장소로 바꾸기 → 링크만 알면 누구나 보고 수정 가능
   - 작성자/수정자(`createdBy`, `updatedBy`), 수정 시각(`updatedAt`), 삭제 표시(`deleted`)는 이미 저장하고 있어서 그대로 쓰면 돼요.
